# divypro
WElCOME TO THE ATTENDANCE TRACKING SYSTEM
<BR>


An Attendance Tracking System designed to simplify and automate the process of recording, managing, and monitoring attendance. The system provides an easy-to-use interface for managing student/employee attendance, viewing attendance records, and keeping track of attendance performance efficiently.
This project aims to reduce manual attendance work, improve accuracy, and provide a centralized platform for maintaining attendance data.
